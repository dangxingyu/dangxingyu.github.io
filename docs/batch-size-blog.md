# Batch-size blog

This research blog is maintained and deployed in its own repository:

- Repository: https://github.com/dangxingyu/batch-size-blog
- Website: https://dangxingyu.github.io/batch-size-blog/
- Local checkout: `../batch-size-blog`

The homepage keeps only the listing URL in `src/lib/blogLoader.ts` and a redirect at `public/blog/batch-size.html`. The redirect preserves query strings and section anchors. Article text, figures, measurements, tests, and deployment belong in the standalone repository.
